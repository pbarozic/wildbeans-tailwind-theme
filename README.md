# Wild Beans ☕

Custom Shopify website developed for **Wild Beans**, a specialty coffee company providing premium coffee experiences for corporate events, private events and brand activations.

🌐 **Live website:** https://wildbeans.fr/

## About the project

Wild Beans needed a modern digital presence that reflected its premium positioning while showcasing its coffee expertise and event services.

I worked on the development and implementation of the website using **Shopify**, with custom sections and frontend components tailored to the brand's visual identity.

The project included both development work and involvement in the broader digital presence of the brand.

## Tech Stack

- Shopify
- Liquid
- JavaScript
- HTML
- CSS
- Tailwind CSS
- Shopify CLI
- Git / GitHub

## Key Features

- Custom Shopify theme development
- Reusable and configurable Shopify sections
- Responsive layouts for desktop and mobile
- Custom frontend interactions and animations
- Content management through the Shopify Theme Editor
- Integration of the brand's visual identity
- SEO and accessibility improvements
- Production deployment and domain configuration

## My Role

I worked on the project from development through to production, including:

- Theme customization and frontend development
- Development of custom Shopify sections
- Responsive implementation
- Content integration
- Testing and debugging
- SEO improvements
- Domain migration and production launch
- Ongoing website improvements

## Context

This project was developed while I was working at Wild Beans in a hybrid role combining operations, specialty coffee and web development.

Working directly within the company gave me the opportunity to approach the website not only from a technical perspective, but also with an understanding of the brand, its customers and its business needs.

## What I Learned

This project gave me hands-on experience working with a production Shopify website and helped me better understand theme architecture, Liquid templates, reusable sections and the challenges involved in translating a brand identity into a responsive website.

It also strengthened my interest in building websites that combine technical implementation with real business and user needs.
